# Browser release 1.17.0

Adds automatic provisional requested-action, reported-condition and claimed-implementation labels for humanitarian access and civilian-protection language. Labels overlap, and conservative rules may abstain. Each label points to original sentence indexes; original transcript records, hashes and numerical denominators are unchanged.

Group metadata and explicit collective openings take precedence over country affiliation. National labels are source affiliations, not independently verified governmental positions. UN and other institutional statements remain separate.

Analysis JSON and CSV include labels and attribution. Saved collections retain a separate versioned label snapshot for every original record. Analysis rejects a snapshot that differs from recomputation against its retained sources and supported method. Legacy collections compute labels on first use. Evidence and overlapping counts appear in downloadable script-free reports.

These are deterministic linguistic cues, not verified conditions, compliance findings or human-reviewed annotations. The rules are scoped to humanitarian/protection language, not a general-purpose discourse classifier. No external AI service is used and no held-out transcripts were opened.

Validation: synthetic overlapping/evidence/negation/future/attribution/tamper checks; analysis, briefing and recovery regressions; fresh-browser source/filter/label restoration; all 13 comparison browser checks; public build. Live acceptance is recorded privately after deployment.
