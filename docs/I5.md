# I5: first extension of the 36-method backlog

This revision adds six bounded research adapters, bringing the executable D1
total to 12 of 42. It does **not** complete the 36-method backlog. M31 and M36
have the narrower scopes below; their remaining layers are still unavailable.
No new adapter can release an analytical email output.

| ID | Executable scope | Boundary |
|---|---|---|
| M08 | Multistart Lloyd k-means on full frozen TF-IDF country vectors | Lexical research partitions, not diplomatic blocs |
| M31 | Full-roster cosine network with a versioned 0.2 edge threshold | No stance or observed-event edges |
| M32 | Weighted Louvain communities | Audit-only lexical graph |
| M33 | Weighted Leiden communities, modularity objective | Audit-only lexical graph |
| M34 | Normalized-adjacency spectral clustering | Rejects isolated nodes and ambiguous eigenspace boundaries |
| M36 | Single-snapshot degree, strength, betweenness, components and density | No network change or temporal claim |

The country roster and feature basis come from the validated M02 artifact.
Clustering uses the full feature space rather than the plotted two-dimensional
coordinates. Fixed seeds, candidate grids, silhouette and minimum-size screens,
and 30 roster-deletion replicates make engineering behavior inspectable. Failed
replicates remain recorded as failures, not zero-valued stability scores.
These screens are not evidence of diplomatic accuracy. All methods retain
source, reference, runtime and content bindings, with independent recomputation
before proof acceptance. Public CSVs in each run's `audit/research/` directory
expose available candidate, membership, resampling and network tables.

The policy is versioned in `un/R/21_research_methods.R`. It caps the country
matrix at 250 rows and 2.5 million cells. Network methods require igraph >=2.1;
missing dependencies produce explicit blocked states. M05 remains the only
conditional ready producer for O3. Exactly O1–O5 are retained.

## Other repairs

- Shiny disconnect cleanup stops the worker safely outside a reactive context;
  a disconnect regression test accompanies the change.
- Progress polling tolerates a not-yet-created progress file.
- The D1 custom-topic note no longer assumes a 39-country run.
- The PDF helper resolves from the installed pipeline root. Renderer availability
  is still a separate environmental requirement; PDF acceptance remains open.
- Strict Base64 validation now applies even when the optional decoder is installed.
- File hashing works on R 4.5 with digest when the newer base-R helper is absent.
- New result fingerprints survive table inspection and save/reload without an
  ALTREP representation change altering their identity.
- New runtime directories are ignored by Git.

## Reproduction

Use a short, disposable copy with fresh local references. Run the scripts in
`un/tests/`: `run_tests.R`, `run_d1_tests.R`, `run_i2_tests.R`,
`run_hierarchical_tests.R`, `run_pam_tests.R`, `run_shiny_adapter_tests.R`,
and `run_i5_tests.R`. Run `un/ui/tests/test_shiny.R` with the UI dependencies
installed. Historical references remain immutable; an incompatible environment
must fail validation rather than refit or silently migrate those references.

See [current acceptance](../un/validation/i5/README.md) for actual results and
remaining acceptance limits.

Algorithm references: [R k-means](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/kmeans.html),
[igraph Louvain](https://r.igraph.org/reference/cluster_louvain.html),
[igraph Leiden](https://r.igraph.org/reference/cluster_leiden.html), and
[igraph betweenness](https://r.igraph.org/reference/betweenness.html).
