# Source-linked briefing — release 1.18.0

The main report now includes up to four source excerpts with requested-action,
reported-condition and claimed-implementation labels, date, source link and
qualified attribution. Selection favors a group request, institutional condition
and country-affiliated request where available, then fills remaining slots.
These deterministic examples are not an exhaustive synthesis or verified outcomes.
Quoted appeals, procedural and biographical examples and unclear sentences are
withheld by the evidence rules. Conference/training claims are not used as
operational implementation examples. No external AI service is called.

“Exclude unresolved passages” removes whole flagged source segments before
analysis and deduplication, including from the single-meeting quick reader.
Only unclear-wording and unresolved recording flags trigger the exclusion;
reported appeals alone do not. The report identifies excluded sources and retains
recording notes. Counts describe the narrowed population; corpus originals,
hashes, coverage, meeting groups and complete label snapshots remain in normal
collection saves. The option persists in the existing versioned saved-filter
schema; older files default to including passages. Invalid option types fail
validation. Standalone report and JSON exports retain the briefing and audit.

Synthetic unit/browser checks cover attribution, unsafe links, whole-passage
exclusion, all-passages mode, no mutation, legacy restoration and saved replay.
The private development collection and all 37 reserved meetings are not published.
