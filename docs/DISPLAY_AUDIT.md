## Source inspection

Fifteen cached source segments were inspected: the top five under each of the
complete, substantive-only and broader inclusion policies. Ranking uses the equal
mean of each passage's mean total variation across the four saved Gaussian-mixture
settings (PCA/LSA × diagonal/spherical), each with four components, regularization
0.0001 and 30 attempted whole-meeting refits. Each passage mean uses only the
successful fits in which that source was present. This averages model sensitivities;
it is not a probability, significance test, representative sample or validated
error detector. Inspecting cached text does not authenticate audio or assertions.

The complete-corpus top five are chair introductions (mean TV 0.540–0.650).
One, `asset/k18/k18iyhzwip#33`, includes unrelated entertainment wording and was
already confirmed as a suspected transcription issue in the owner's review. It
remains excluded from both reviewed subsets. Repeated protocol language and long
ministerial titles are relevant to these textual groupings; this does not identify
a cause of a particular numerical change.

The substantive top five are recorded under Palau (0.567), Fiji (0.535), Vanuatu
(0.509), Seychelles (0.506) and Guinea-Bissau (0.502). They combine multiple issues

## UMAP sensitivity protocol

Six frozen matrices come from the existing reviewed comparison: 458 complete,
194 substantive and 198 broader-subset usable records, each under PCA and LSA
with 20 retained dimensions. The saved diagonal-mixture memberships supply map
colors only. Seeds 7, 42 and 2026 crossed with 5, 15, 30 and 50 UMAP neighbors give
**72 layouts**. Minimum distance stays 0.1, spread 1 and epochs 300 in umap-js 1.4.0.
The default seed-42/15-neighbor result exactly reproduces the prior saved layout.
Score/ID/membership hashes stay unchanged throughout; no representation or cluster
is refitted in the display sweep.

Neighborhood overlap, trustworthiness and continuity use a fixed evaluation size
of ten, independent of UMAP's fitting neighborhood. Squared-distance ties use the
existing rounding-to-12-decimals then row-order rule. All three measures are 0–1,
higher better for local geometry, not semantics. Pairwise comparisons between the
three seeds at each neighborhood size give **72 seed-pair checks**. This separates
repeat-layout agreement from preservation of retained-score neighbors. Three seeds
are an exploratory grid, not uncertainty intervals or proof of general robustness.

Substantive PCA layouts retain 0.502–0.568 of their ten nearest score-space neighbors;
LSA layouts retain 0.518–0.589. Same-setting seed-pair overlap spans 0.589–0.745 for
PCA and 0.601–0.780 for LSA. Thus both settings and initialization deserve inspection.
These diagnostics cannot be multiplied by TF-IDF-to-score preservation to claim an
end-to-end fidelity probability.

A separate browser-versus-Node check found the same source identities and hard
assignments, with score and membership differences below 1e-12, but different
UMAP layouts despite seed 42. Cross-run ten-neighbor agreement was 0.738 (PCA)
and 0.693 (LSA). This execution-path comparison is separate from the frozen-input
grid. Save exported coordinates for exact map reproduction; a seed alone does not
guarantee the same map across environments. Within the same browser, enabling MDS
leaves all source scores, memberships, UMAP coordinates and grouped-refit results
exactly unchanged in the real 194-passage comparison.

## Metric MDS implementation

MDS minimizes the sum over all unordered pairs of `(target distance − displayed
distance)^2` with equal pair weights, including pairs whose target distance is zero.
Targets are Euclidean distances in all retained, unwhitened PCA/LSA dimensions.
There is no nonmetric rank transformation, sparse neighbor graph, hidden sampling
or inference of clusters from the two-dimensional display.

The original JavaScript kernel implements metric SMACOF: each majorization update
is `B(X) X / n`, with off-diagonal ratio based on target/current distance, centered
coordinates and a finite, nonincreasing-stress guard. A zero displayed separation
uses a zero ratio; a completely collapsed initialization with positive targets is
rejected. Exact zero target geometry returns a degenerate display with undefined
relative-error diagnostics, not perfect substantive validity.

Defaults are three seeded uniform-random starts, seed 42, two output dimensions,
up to 1,000 iterations, and tolerance 0.000001. Initial coordinates are centered and
scaled to target RMS pair distance. A start stops when stress decrease divided by
the current sum of squared display distances falls below tolerance. The lowest
finite raw stress wins across all starts; if that selected run reaches its limit,
the layout is explicitly provisional. Numerical failures are recorded, and all
failed starts withhold MDS only; clustering remains available. Cancellation releases
no partial report. Supported controls: 1–5 starts, 10–1,000 iterations, integer seed;
the existing browser limit is 600 selected passages with at least four usable rows.

The first audit used 300 iterations. Four of six selected layouts were unfinished,
so the comparison was repeated with a 1,000-iteration ceiling. All 18 starts in the
second audit converged; selected solutions required 246–421 iterations. This is a
numerical stopping result, not proof of a global optimum or validated representation.
The original 300-step audit remains part of the validation evidence.

## Distance and neighborhood tradeoff

For cross-display distance comparison, a single nonnegative uniform scale is fitted
by least squares before computing `||target − scale × display|| / ||target||` over
all pairs. UMAP has arbitrary coordinate scale, so comparing its unscaled raw stress
would be misleading. Within MDS, fitting and start selection still use native raw
stress. Its diagnostics also report target-normalized relative error and Stress-1
(the square root of raw stress divided by squared display distances). These two
denominators are named separately. No borrowed qualitative quality cutoff is used.

| Inclusion | Representation | UMAP neighbor overlap | MDS neighbor overlap | UMAP scaled distance error | MDS scaled distance error |
|---|---|---:|---:|---:|---:|
| full | PCA | 0.544–0.597 | 0.369 | 0.379–0.504 | 0.249 |
| full | LSA | 0.549–0.601 | 0.376 | 0.371–0.511 | 0.248 |
| substantive | PCA | 0.502–0.568 | 0.322 | 0.385–0.525 | 0.345 |
| substantive | LSA | 0.518–0.589 | 0.330 | 0.385–0.566 | 0.344 |
| inclusive | PCA | 0.517–0.577 | 0.288 | 0.389–0.527 | 0.343 |
| inclusive | LSA | 0.510–0.579 | 0.292 | 0.390–0.552 | 0.342 |

In every fixed-input comparison, the selected MDS display has lower global distance
error and lower local-neighbor preservation than the tested UMAP layouts. This is
an objective tradeoff, not a winning-method claim. Compare within rows: subset
changes alter the population and score geometry. Plots preserve equal x/y scale;
orientation and bounds remain arbitrary. Colors represent the same saved hard or
highest-membership assignment within each representation, not shared component IDs
across PCA and LSA.

The MDS distance plot includes every pair in twenty equal-width target-distance
bins. Marks show mean target/display distance and observed display minima/maxima,
not confidence intervals. Per-passage distortion is its RMS incident distance error
divided by the global RMS target distance. Source IDs and coordinates allow every
calculation to be reconstructed. JSON saves all starts and histories; Cluster data
CSV adds MDS1/MDS2 only when an MDS layout is available; standalone HTML includes
maps, diagnostics and source links without scripts.

## Validation and reproduction

```text
python tools/inspect_gmm_passages.py corpus.json gmm-output display-output
node tools/audit_umap.cjs gmm-output display-output/umap.json
node tools/audit_mds.cjs display-output/umap.json display-output/mds-300.json 300

python tools/check_display_reference.py display-output/umap.json --mds display-output/mds.json --node node
node tools/test_browser_mds.cjs
node tools/test_mds_ui.cjs site corpus.json completed-review.json browser-output
```

The renderer also uses the preserved `mds-300.json` audit for its iteration-limit
comparison. The commands above retain it separately; render both limits with
`node tools/render_display_audit.cjs display-output site/display-audit.html`.

NumPy/SciPy independently reconstructed every UMAP fidelity metric, scaled distance
error and seed-pair overlap. A 50-step fixed-initialization SMACOF fixture matches
scikit-learn 1.7.2; the six actual selected starts also match independent SMACOF,
with maximum coordinate difference below 2e-13. Initial coordinates are shared,
while majorization and distance evaluation are independent. Tests cover exact
planar geometry, duplicate/zero targets, stress descent, iteration limits,
reproducibility, cancellation and unchanged memberships/UMAP/grouped refits with
MDS enabled. See [validation](display-validation.json) and [saved comparison](display-comparison.json).
The frozen R D1 pipeline and its release gates are unchanged.

## Recommended next steps

1. Check the flagged transcript wording against source audio before factual reuse.
   Keep any correction as a separate, provenance-bearing layer.
2. Pilot reviewed within-speech units with parent IDs and character offsets if
   the goal is issue-specific grouping. Preserve these full-segment comparisons
   to show the effect of changing the analytical unit.
3. Add independent meetings before stronger stability claims. Further methods
   such as spectral clustering or diffusion maps need their own assumptions and
   validation; they will not resolve source quality or multi-issue segments alone.
