# Repeated synthetic reopening sampling

The test-only sampler reopens the unchanged fictional ten-year report six times in fresh browser contexts, with three ordinary and three sampled runs in balanced order. Every run checks exact saved payload, visible summary and all filters, 772 charts and zero source-shard fetches. No original collection, source text or holdout is used.

Sampling requests a 1 ms interval. Each sample is weighted by its corresponding time delta; unrepresented trailing profile time remains explicit. Exact local script URLs permit application-function naming; unknown, native, program, idle and garbage-collection samples retain separate buckets. Sample intervals are not exact function CPU duration or fractions of report wall time. CPU capture includes profiling boundaries outside the independently marked timeline window. Timeline complete events are restricted to the document marker thread and clipped, then unioned within each category. Categories can overlap and cannot be summed. Missing categories do not establish absence of work. Raw profiles, stacks and traces are discarded in memory.

Actual isolated Edge final ordinary min/median/max was 615.20/615.72/629.23 ms; sampled min/median/max was 663.85/666.25/671.13 ms. These ordered host measurements do not estimate causal overhead or improvement. Across sampled runs, the display function accounted for 40.42-43.60 ms of weighted leaf intervals, serialization 15.71-16.81 ms and report freezing 9.42-10.87 ms. Program and unattributed intervals remained much larger and cannot be assigned to native rendering by assumption. Timeline Layout measured 75.16-75.34 ms, style-tree updates 34.45-36.70 ms and HTML parsing 34.15-35.61 ms; these overlap. Maximum long tasks remained 321-329 ms. The residual stall is still not fully attributed.
