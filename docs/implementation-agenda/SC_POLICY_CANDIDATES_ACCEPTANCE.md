# Private humanitarian topic-relevance candidates

A separate read-only validator connects source-verified provisional resolution relevance to exact selected adopted voting actions. It does not modify the selected-action cache, original votes or inherited binding artifacts. It does not create national statement positions, issue agreement, a public snapshot or accepted comparison data.

The validator requires official HTTPS UN document URLs, exact document bytes/hashes, safe proof paths, canonical adopted-resolution identity and version, supported humanitarian policy objects and the explicitly scoped thematic armed-conflict context. Unique selected DDL action identity and ballot stage/version must match. Missing, source-only or ambiguous action matches remain gaps; an adopted-text binding never transfers to a failed draft. Candidate metadata stays separate from ballots, and multiple policy candidates count as one distinct action.

Only assistant-provisional relevance is supported by this lane. Every candidate explicitly has `comparable:false`, `comparisons_eligible:false` and `issue_agreement:false`, overriding the inherited generic binding flag without rewriting it. Exact operative-paragraph references, stated qualifications and source limitations remain attached. The tool verifies provenance and structured identity; it does not automatically prove the semantic correctness of an arbitrary rationale or paragraph anchor. Actual source-content review is a separate acceptance step.
