# Synthetic report reopening profile

The separate test-only harness uses the existing invented ten-year report and compares ordinary and instrumented reopening in isolated fresh browser contexts. It checks exact saved report, structured summary, visible filters, all 772 charts and zero source-shard fetches. No actual country evidence, private collection or reserved source is processed.

Synchronous wrappers preserve property descriptors and receivers, and restore original functions before saved-result parity checks. Inclusive times overlap; exclusive times subtract only directly nested instrumented calls and are not exhaustive CPU accounting. File reading is asynchronous elapsed time, not a synchronous child. Observing its promise adds a rejection handler, so this successful-fixture test does not claim unchanged unhandled-rejection observability. Main-thread long-task counts cover tasks starting within each phase.

Host scheduling and ordered execution confound differences between the ordinary and instrumented run. A faster instrumented run is not an optimization result. Post-ready frame measurements alone can miss earlier style/layout work; the browser timeline is used to investigate the unattributed stall. No production optimization or responsiveness threshold is accepted by this diagnostic.

Actual isolated Edge execution passed with the existing fixture: ordinary reopening 642.86 ms and instrumented reopening 627.60 ms. This difference is descriptive, not a speed improvement. Wrapped calls measured HTML insertion 37.2 ms, HTML generation/validation 15.9 ms and report reopening 8.1 ms. Main-document timeline category unions measured Layout 67.15 ms, UpdateLayoutTree 25.16 ms, ParseHTML 31.16 ms, PrePaint 16.18 ms and Paint 3.85 ms. Categories overlap and must not be summed. Missing RunTask events mean that category was not captured, not that no tasks ran. The setter-to-first/second animation-frame windows were 112/128.6 ms, reflecting scheduling opportunities rather than CPU time. The broader main-thread stall remains incompletely attributed.

Syntax and actual saved-result parity passed; original application assets remain unchanged. Independent review and GitHub publication checks follow. Source-bearing trace material is not published. Only aggregate synthetic engineering results belong in the public acceptance record.
