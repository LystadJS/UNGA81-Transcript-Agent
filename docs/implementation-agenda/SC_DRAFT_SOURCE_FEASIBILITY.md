# Security Council draft-vote source: bounded discovery

The [official Security Council voting-records page](https://main.un.org/securitycouncil/en/content/voting-records-1992) describes a separate dataset covering draft resolutions from January 1992 onward, including member votes, outcomes, agenda items and meeting records. It links to the [Peace and Security Data Hub DPPA-SCVOTES catalog](https://psdata.un.org/dataset/DPPA-SCVOTES). The official page describes agenda-based topic categories as informational; those categories are not source-validated humanitarian policy bindings.

The catalog returned a JavaScript application shell. A usable download endpoint, actual header/schema and record-level completeness have not yet been verified. This discovery does not establish that a full ten-year rejected/vetoed-draft archive has been acquired, and no adapter or policy bindings were created.

The next bounded acquisition task is to use the normal official catalog interface to obtain its metadata and complete samples of one vetoed draft, one otherwise unsuccessful draft and one adopted draft, capped at 45 member rows. Record exact URLs, hashes, headers, draft/version identities, outcomes, ballot modality, dates and meeting links. Verify whether amendments/procedural votes are included or excluded from the actual feed. Do not convert unanimous or non-ballot adoption into individual affirmative votes without explicit ballot evidence. Confirm eligible members separately from source non-voting codes.

Keep this family separate from the already ingested Dag Hammarskjold Library adopted-resolution/decision families. Reconcile each sampled draft group and preserve outcome/stage/modality before implementing a strict adapter. Source access and sample acceptance are the next gates, followed by bounded pinned-window ingestion; neither task establishes country positions on isolated provisions or semantic-model acceptance. No raw transcripts, historical holdouts, database records or public raw data were used for this discovery.
