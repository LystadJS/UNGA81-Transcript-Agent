# Private whole-artifact segment batches

A separate versioned private batch layer persists metadata for every segment of a supplied transcripts.un.org artifact. It invokes the source-specific audit from complete raw bytes internally; caller-prepared row sets cannot replace that validation. Source-provided statement numbers remain artifact-bound locators, not persistent intervention IDs or complete speech boundaries.

The batch manifest defines exact current membership. A stable parent artifact source points to a revision; child segment identities include the raw artifact hash. On a new parent revision, prior manifests and provenance become invalid while historical segment metadata remains stored. Reading current membership must verify the manifest, current parent revision, member identities/revisions, private family/attribution state and dependency provenance. Listing all stored segment sources is not a valid current-membership query.

All parent, segment, provenance and manifest writes share one outer transaction. A malformed record, failed member write, stale historical replay, invalid existing artifact or failed manifest acceptance rejects the entire attempt. Repeating identical bytes, receipt, frame and method pins is idempotent. Receipt/frame/method identities participate in provenance; a changed pin requires revalidation even when raw bytes match. The getter fails closed on invalid or inconsistent current state rather than silently falling back to a superseded artifact.

Stored metadata excludes transcript wording. Segment families stay separate from national statements and votes; countries remain empty and capacity unknown. The source modality remains automatic speech recognition, not an official UN record. Whole-supplied-artifact consistency does not establish remote completeness, speech boundaries, source accuracy, national attribution or historical archive coverage. Production opinion intake, public release and fitted models remain unaccepted.
