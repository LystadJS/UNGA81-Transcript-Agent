# Private normalized statement identity

A separate versioned adapter and private store bridge give each native statement record its own identity under a parent meeting and artifact. This addresses the earlier risk of a caller reusing one meeting-level source ID for several speakers. Existing discovery, normalized adapters, source cursors and previously accepted caches remain unchanged.

Identity and revision serve different purposes. Exact native meeting/statement keys, their declared scope and language establish identity; corrected text, artifact hashes and attribution metadata belong in immutable source revisions. The bridge preserves parent-artifact provenance and invalidates dependent artifacts on relevant revisions. Known historical parent or statement revisions cannot be replayed over a different current revision, including an old parent attached to a newly seen statement key. Already-invalid provenance is rejected inside the same transaction. This is a known-history safeguard, not authentication of chronological order for never-seen artifact bytes. Previously stored statement metadata is not silently rewritten when a parent changes; downstream consumers must require valid provenance before accepting observations.

The adapter verifies the supplied normalized text hash and structured parent/source linkage. It does not independently authenticate raw source bytes, archive-member correspondence or a caller-declared source role. A valid normalized record cannot replace the stricter historical original-source and development-allowlist gates documented in HISTORICAL_TRANSCRIPT_FEASIBILITY.md. Production source-specific intake and migration/replay remain separate acceptance work.

National, collective and unknown capacity remain distinct. A recorded affiliation alone does not establish national capacity or an explicit national policy position. The bridge stores private metadata/provenance only and creates no observations, votes, owner-confirmed labels or public bundles. Source text is excluded from stored metadata outputs.
