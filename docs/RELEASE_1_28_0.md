# Release 1.28.0 — nearby-date comparisons

Every report now includes a separate nearby-date section, automatically covering all recorded countries and supported policy questions. The saved window defaults to seven days (0–14 allowed). Both dates, the signed U.S.-minus-country difference and linked evidence remain visible.

Matching explicit questions and contexts can show same or opposite direction on different dates. A separately labelled shared-priority finding currently covers bounded child-protection declarations and national-strategy plans; it never establishes endorsement of the same strategy. Qualified, conflicting, domestic, unspecified-context, unresolved and non-national material cannot establish exact-policy direction. A closer qualified date blocks selection of a farther simple position. Equally near dates are shown separately. No cross-date finding enters the same-day score, is carried forward, or establishes overall diplomatic alignment.

Saved collections retain the window and original sources; findings are recomputed from retained text rather than trusted from imported review notes. HTML and a dedicated CSV retain dates, distinctions, qualifications and both source identities. Existing filters and same-day results remain unchanged apart from the new default parameter.

Validation: synthetic direction, date, tie, context, attribution, qualification and duplication cases; desktop/mobile browser save/reopen and export tests; existing policy and collection regressions. Private Palau replay is a development check, not independent accuracy validation or owner-confirmed review. Private transcript inputs are not published. The 37 reserved meetings remain unopened.
