# Browser release 1.33.0 — first ten-year humanitarian issue workflow

Open `issue.html` from the report builder. Load a saved current collection and an optional historical saved collection. The briefing dates and ten-year historical as-of date are independent. Historical records cannot add countries' current expressions to the selected proceedings. Original transcript records, filters, review notes and documentary evidence are preserved in the saved issue collection.

The report automatically includes recorded country affiliations, current country-level opinion distributions per policy/context, a country/year coverage heatmap, source-coverage table, U.S. reference history, country position tables and monthly observed country–U.S. trajectories. Humanitarian access and civilian protection are separate questions. Comparisons require explicit positions on the same context and date; conditions alone, broad aid mentions, institutional/group attribution, unresolved wording, conflicting source hashes and missing evidence cannot establish a direction comparison. Duplicated passages add no position weight. Unknowns remain in current-country denominators. The primary source collection defines current briefing evidence; historical imports extend only history.

Save/reopen retains historical evidence and workflow settings, regenerates identical deterministic results and exports script-free HTML. Issue collections reopened in the main report builder automatically include the issue report as well. Source text hashes are verified in the issue importer; record and character limits are explicit.

This is observed-position reporting, **not a released trajectory model**. No curve, inference, uncertainty interval or forecast is fabricated. The page explicitly shows incomplete coverage, partial calendar-year endpoints and withheld modeling. It does not fetch or claim a complete ten-year historical archive, expose restricted historical research data, or alter frozen research/publication gates. Assembly of a source-validated ten-year issue archive and calibration of a policy-specific estimator are subsequent milestones.

Validation: synthetic historical/current separation, exact-date/context comparisons, country weighting, duplicate invariance, attribution abstention, conflicting sources, leap-day bounds and gap display; browser save/reopen, original-filter preservation, source corruption rejection, script-free export and responsive layout. Existing country/report regression checks remain in place. No reserved transcripts were opened.
