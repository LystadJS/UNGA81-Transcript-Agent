Execution and methodological boundary

Every imported row retains its original observation ID, text hash, source metadata, status, and missingness. Cross-source or cross-geometry numerical comparisons are withheld; there is no automatic model winner.

Local MiniLM feasibility and network handling

The lab does not download model weights or tokenizer files and makes no third-party network requests. Optional MiniLM would require an explicitly pinned, locally served model package; tokenizer parity, model license and file sizes, WASM/WebGPU fallback, accuracy against pinned offline outputs, browser caching, privacy review, and desktop/mobile memory benchmarks before activation. Existing pinned MiniLM representations may be imported only through source-verified offline interchange results. Local inference is not advertised as implemented.
