What the exports contain

HTML is a standalone, script-free report suitable for printing. JSON preserves the original collection, source hashes, meeting selection and mission preferences so the report can be rebuilt here. CSV contains all passages from the selected meetings—not only the search results—with source identifiers and hashes. Potential spreadsheet formulas are prefixed with an apostrophe; JSON retains exact text.
