Personal setup and limits

Run PYTHONPATH=src python -m un_transcript.report_draft input.json --output draft.json --model YOUR_LOCAL_MODEL from your project checkout. The default endpoint is http://127.0.0.1:11434/v1/chat/completions; use --endpoint to change it. Configure a local model with cloud routing disabled: a loopback address alone cannot establish where inference runs. No model is bundled or downloaded by this project. Up to eight questions and 100 matching passages fit within a 64 KiB input. Nothing is silently truncated.
