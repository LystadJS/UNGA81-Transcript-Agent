# Visual review example

Open `review/index.html` in a browser, or extract `review.zip` into a short
folder and open its `review/index.html`.

This pack contains the actual HTML/unsent EML from the validated I5 23 September
replay and a separate, explicitly audit-only gallery of four original charts.
It is a frozen design-review example, not a current daily briefing. Withheld
charts were not inserted into the actual email. Native Outlook rendering has
not been tested.

Gallery controls let you try spacing, font size and section blue. They do not
alter the saved email or raster chart pixels. Download review notes to share
the desired edits. No form or email is submitted. The HTML works offline.

The builder is `tools/build_review.py`; it requires an existing validated run.
`review/provenance.json` records file hashes. The package uses the approved USUN
theme and seal with the project's own identity; it is an internal, non-final
working example, not a claim of official clearance.
