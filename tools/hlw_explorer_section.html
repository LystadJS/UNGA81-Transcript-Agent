Passage similarity · PCA projection

Each point is one unique candidate passage. Select a point, or tab to it, to read the source. Positions are a lossy two-dimensional view; groups are calculated using the full TF-IDF vectors.

Group descriptors are the six highest mean TF-IDF terms. Bar lengths show the share of all selected passages. These are automatic descriptors, not reviewed theme names.

How separated are the groups?

Compare mean cosine silhouette across five cluster counts. Larger values mean stronger separation under this representation; the scale runs from −1 to +1.

Which restriction issues overlap?

Jaccard overlap: shared source segments divided by segments containing either issue. Counts below each percentage make the denominator visible. Segment co-occurrence does not establish that both issues refer to Cuba.

Diagonal cells show each issue’s segment count. This is descriptive association within the selected corpus, not a significance test or causal relationship.

Inspect methods, source data and limitations

Selection: restriction-topic evidence rows in source segments that also have a Cuba-topic match. Identical statement and character-offset hits are collapsed across topics. Generic restrictions can remain in this candidate screen; review the source before calling a passage embargo-specific.

Representation: lowercase English unigram TF-IDF, English stop words, sublinear term frequency, smooth inverse document frequency, L2 normalization. PCA centers the vectors and uses full SVD. Average-linkage hierarchical clustering uses cosine distance on the full vectors. The default cluster count has the highest observed silhouette among 2–6, with no claim that it is the true number of themes. All selected passages are retained.

Automatic transcription errors, repeated diplomatic phrases, passage length and multiple passages from one speaker can influence the result. These are not independent population samples: no inferential p-values, confidence intervals, sentiment or stance labels are reported. This selected-passage experiment does not rerun or release the frozen D1 methods; the original full-corpus research gate remains in force.
