# Independently constructed synthetic stance holdout, frozen before scoring

- Protocol: `un.stance-separate-holdout.v1`; authoring authority: coordinator, **not** the PR #66 worker's development fixture/code.
- Separate from previous 4/16/30-family development fixtures. Text and labels are invented English, created and committed in this coordinator-owned namespace **before any execution**. This is an independently *constructed* holdout, not independent human annotation or a representative probability sample.
- Restriction: no original UN or private meeting text, no reserved 37 October 2026 transcripts, no external text service and no training/tuning of PR #66's fixed methods.
- Population is fixed at **42 families × 4 source-matched text variants = 168 observations**, six families each in: `direct`, `indirect`, `nested_negation`, `attributed`, `conditional`, `scope_shift`, `cue_free`. All source ids, hashes, labels, stratum sizes, exception cases, and expected distinctions must be frozen prior to execution.
- Every family has `anchor`, `paraphrase`, `opposite`, and `protocol`. `paraphrase` and `anchor` express the same authored proposition-direction; `opposite` and `protocol` contradict it *for the three scored strata*, except changed-proposition guard cases where ordering is not meaningful. Labels are design labels, not authenticated speaker/country stances.
- **Evaluable denominator:** 18 families (direct, indirect and nested_negation); compare anchor→paraphrase versus anchor→opposite, tie fails. **Guard denominator:** 24 families (attributed, conditional, scope_shift, cue_free), requiring no confident claims from sign-gated S1 or S2 across *all 3 candidate comparisons per family*: 24 family abstentions/72 pair opportunities. Explicitly report no-output, false confident, failed encodings and omitted rows.
- Models, untouched: M0 exact pinned MiniLM ONNX cosine, L0 word 1–2 gram L2 TF-IDF fit once to exactly the 168 frozen synthetic statements; S1 exact PR #66 `scored_pair(case,role,cosine,sign_weight=0)`; S2 exact PR #66 `scored_pair(case,role,tfidf,sign_weight=2)`. The same source ids/text SHA and order for all. No dev-case reuse. No new stance model, thresholds, model selection or adjustment after looking at holdout outcomes.
- **Decision rule frozen:** a method merits a *subsequent third-party reviewed synthetically labeled study* only if ≥16/18 correct evaluable-family orderings, ≥23/24 complete guard-family abstentions, 0 unsupported confident outputs on guard comparisons, 0 missing results or silent encoder failures, full integrity-tamper refusal, and the two-process identical receipt. Merely meeting these design-dependent synthetic thresholds never authorizes real-source holdout access, empirical inference, or deployment. A failed threshold or excess abstention blocks advancement.
- This evaluation is an **audit of whether development-optimized handcrafted features generalize to differently worded synthetic expressions**. Do not conflate abstention with incorrect stance, nor the raw cosine scores with a stance prediction. Preserve all adverse outcomes, including any candidate's inability to cover evaluable families.
- The authentic archived historical TF-IDF/LSA model is not present and will remain NOT RUN. A newly fitted synthetic lexical comparator is not a substitute for that model. S1/S2 share a signed rule and synthetic proposition IDs; their agreement is not independent confirmation.
- Holdout files remain coordinator-only and are read by an isolated test branch created from current `main` plus *immutable PR #66 source blobs* (no worker edits). A GitHub-hosted full checkout runs pinned Python 3.13, original model/checkpoint artifact hash verification, adversarial negative controls, two independent processes, exact JSON receipt equality, and GitHub Actions status. No public checkpoint or vector artifact is committed. If execution fails, retain all attempts and correct only coordinator-owned runner issues before rerun, never alter labels or worker methods.
